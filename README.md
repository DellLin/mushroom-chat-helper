# 蘑菇聊天小幫手 (mushroom-chat-helper)

<img src="assets/icon-256.png" width="96" height="96" alt="蘑菇聊天小幫手圖示" />

[![CI](https://github.com/DellLin/mushroom-chat-helper/actions/workflows/ci.yml/badge.svg)](https://github.com/DellLin/mushroom-chat-helper/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/DellLin/mushroom-chat-helper?display_name=tag)](https://github.com/DellLin/mushroom-chat-helper/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

有鑑於新楓之谷：經典版的聊天室窗並沒有頻道分類的功能，部分玩家需要社交能量來當坐牢的精神糧食，而大量的廣播會把訊息快速洗掉。
此工具主要就是把把遊戲聊天視窗裡「你在乎的頻道」單獨拉出來,顯示成一個可以疊在遊戲上的獨立小視窗，讓你不會遺漏訊息。

判斷頻道的方式是**文字顏色**,抓到訊息後直接把擷取到的
畫面截圖顯示出來,所以看到的字跟遊戲裡長得一模一樣,不會有誤字。

**完全唯讀**——只擷取畫面,不讀寫遊戲記憶體、不注入、不模擬任何操作。

例:建立一個「社交」檢視 = 密語 + 好友 + 公會,獨立視窗就只顯示這三種對話,
再開啟置頂、把視窗貼齊遊戲原本的聊天視窗,就是一個濾過的聊天覆蓋層。

## 系統需求

- Windows 10 1903 以上

## 下載

到 [Releases](https://github.com/DellLin/mushroom-chat-helper/releases/latest) 下載
`mushroom-chat-helper-vX.Y.Z-windows-x64.zip`,解壓縮後直接執行裡面的 exe,不用安裝。

## 自行建置

安裝 [Rust](https://rustup.rs)(stable),然後:

```bash
cargo build --release
```

產出 `target/release/mushroom-chat-helper.exe`,單一執行檔、零外部 DLL。
設定檔 `mushroom_chat_helper.toml` 會在第一次儲存設定時建立於執行檔旁邊。

## 快速上手

1. 先開好遊戲，並且把對話聊天室窗展開
2. 啟動本程式。若有視窗標題剛好等於預設的篩選字串
   (`新楓之谷：經典版`),會**自動開始擷取**,可以直接跳到第 4 步。
3. 按主視窗右上角的 **⚙** 打開設定視窗 →「擷取設定」→ 選擇遊戲視窗 →
   **▶ 開始擷取**。
4. 設定擷取範圍(ROI)。ROI 要**剛好框住聊天視窗最下面那一行**的高度:
   - **一般設定**:選遊戲視窗的解析度就好,直接套用該解析度下實測的座標。
     程式偵測到擷取畫面的大小後也會自動幫你選。
   - **進階設定**:在預覽圖上拖曳框選、手動輸入座標,或按 **在畫面上框選**
     開全螢幕工具精準框(見下方「全螢幕框選 / 吸色工具」)。
5. 到「頻道」分頁,點各頻道的色票 →「吸取畫面顏色」,直接從遊戲畫面上
   點該頻道的文字取樣。**預設顏色只是近似值,第一次使用務必校正。**
6. 到「檢視管理」建立自己的分頁(例如「社交」= 密語 + 好友 + 公會)。
7. 關掉設定視窗,回主視窗切換檢視。想疊在遊戲上就勾「視窗置頂」,位置調好後
   按 **🔒** 鎖定,避免誤觸拖曳。

## 介面配置

### 主視窗

- **工具列**(頂端):檢視切換(全部 + 自訂檢視)、清空訊息、截圖放大倍率、
  視窗置頂、⚙ 設定、🔓/🔒 鎖定。
- 工具列**背景可以拖曳**移動視窗;視窗**右邊、下面、右下角**可拖曳縮放
  (上面跟左邊刻意拿掉,避免點工具列按鈕時誤觸)。
- **🔒 鎖定**後拖曳與縮放都會停用,疊圖對好位置後不怕誤觸。
- 結束程式的按鈕收在設定視窗裡(主視窗沒有關閉鈕)。
- 視窗位置與大小會自動記住,下次啟動還原。

### 設定視窗

按 ⚙ 開啟，內有四個分頁:

| 分頁       | 內容                                                                              |
| ---------- | --------------------------------------------------------------------------------- |
| 🎥 擷取設定 | 選擇遊戲視窗、開始/停止擷取、處理頻率、畫面去重時間窗、ROI(一般/進階)、主畫面判斷 |
| 🎨 頻道     | 各頻道的顏色、容差、啟用與否,新增/刪除頻道                                        |
| 📑 檢視管理 | 訊息顯示選項、文字大小、「全部」檢視的行為、自訂檢視、切換檢視的快捷鍵            |
| ❓ 說明     | 內建的簡要使用說明                                                                |

### 全螢幕框選 / 吸色工具

- **框選 ROI**:點一下設定起點,再點一下設定終點。
- **吸取顏色**:點一下就直接套用該像素的 RGB。
- **W / A / S / D** 每按一下把準心精準微調 1 個像素(畫面通常是縮小顯示,滑鼠
  一個螢幕像素常常已經跨過好幾個擷取畫面像素)。
- **Esc** 取消。

## 系統層級快捷鍵

預設 **Ctrl + Shift + Tab**。這是用 Win32 `RegisterHotKey` 註冊的**全域**快捷鍵,
不需要本程式在前景,**遊戲視窗有焦點時也能觸發**。按一次循環切換檢視:

```
全部 → 檢視1 → 檢視2 → … → 全部
```

可以在「📑 檢視管理」分頁自訂組合鍵(Ctrl / Alt / Shift / Win + 按鍵)。
若選到的組合鍵已被其他程式佔用而註冊失敗,畫面上會跳出紅色提示。

## 主畫面判斷

進入商城、拍賣等畫面時,原本的聊天視窗不在畫面上,繼續套用顏色判斷只會誤判出
訊息。「主畫面判斷」用一個小範圍 + 一個目標顏色來偵測「現在是不是在遊戲主畫面」——
只有在主畫面才會出現的顏色出現在那個範圍內,就視為在主畫面,否則暫停處理。

系統預設判斷購物商城按鈕區域是否存在畫面上來判斷是否在主畫面。

搭配「檢視管理」裡的**自動隱藏聊天視窗**(預設開啟),離開主畫面時會把整個聊天
視窗暫時搬到螢幕外,回到主畫面再自動搬回原位,置頂的視窗才不會擋住商城畫面。

這個功能可以在「擷取設定」分頁關掉;它的判斷範圍與顏色同樣可以用框選/吸色工具
校正。

**自動隱藏不會把視窗藏到叫不回來**,以下情況一律會把聊天視窗放出來:

- **剛開啟應用程式的前幾秒**——不管判斷結果是什麼,「關掉重開」永遠看得到視窗。
- **擷取的遊戲關閉**(或最小化、擷取停掉/卡住)——沒有畫面就沒有判斷依據。
  遊戲視窗被關掉時還會直接停止擷取,聊天視窗上會出現一條提示。
- **判斷顏色還沒校正好**——主畫面判斷必須先真的認出一次主畫面,之後才有隱藏
  視窗的權力。所以換了解析度、顏色沒對上時,最多是不再擷取到新訊息,不會變成
  視窗消失不見。重新校正判斷顏色/範圍後,一樣要重新認過一次。

## 提升分類準確率(重要)

- **第一次使用務必用「🎯 吸取畫面顏色」校正每個頻道的顏色**,預設值只是近似值
- ROI 請貼齊**單一則對話的高度**,框太高會混進上下相鄰的訊息一起分類
- 容差別一次調太寬。寬容差雖然比較容易「抓到」文字,但也容易把不同頻道的顏色
  混在一起而誤判分類
- 用不到的頻道直接取消勾選,少一個顏色參與比對就少一分誤判機會

## 已知限制

- 遊戲最小化時擷取會暫停(Windows.Graphics.Capture 的限制)
- 遊戲視窗大小或聊天視窗位置改變後,ROI 需要重新設定
- 顏色分類本質上是近似判斷,不同頻道顏色太接近時容易誤判,需要仔細調整容差
- 沒有明確命中任何頻道文字顏色的訊息(未分類)一律不顯示
- 同一則訊息因背景抖動重新觸發時,靠「畫面去重時間窗」(擷取設定分頁)過濾;
  時間窗太短會偶爾看到重複,太長則可能誤擋短時間內出現的相似新訊息

## 設定檔

設定存在執行檔旁的 `mushroom_chat_helper.toml`,按各分頁的「💾 儲存設定」或結束
程式時寫入。刪掉這個檔案就會回到出廠預設值。

主要欄位:

| 欄位                | 預設               | 說明                                                       |
| ------------------- | ------------------ | ---------------------------------------------------------- |
| `window_title_hint` | `新楓之谷：經典版` | 視窗清單的篩選關鍵字;完全相符時啟動自動開始擷取            |
| `fps`               | `12`               | 每秒處理幀數(2~15)                                         |
| `roi` / `gate.roi`  | 2560x1440 實測值   | 聊天範圍 / 主畫面判斷範圍                                  |
| `dedup_seconds`     | `5`                | 畫面去重時間窗(秒)                                         |
| `image_scale`       | `1.0`              | 截圖顯示放大倍率(1~8)                                      |
| `ui_font_px`        | `16.0`             | 整個程式的文字大小基準(8~40)                               |
| `show_message_meta` | `false`            | 是否顯示每則訊息的時間戳/頻道標籤                          |
| `all_view_mode`     | `ShowMessages`     | 選「全部」時隱藏聊天(透出遊戲原本的聊天視窗)或顯示全部截圖 |
| `hotkey`            | `Ctrl+Shift+Tab`   | 切換檢視的系統層級快捷鍵                                   |
