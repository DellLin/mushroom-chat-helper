# 楓之谷聊天篩選器 (maple-chat-filter)

以畫面擷取 + OCR 建立自訂聊天頻道檢視的獨立視窗工具。
**完全唯讀**:只擷取遊戲畫面,不讀寫遊戲記憶體、不注入、不模擬操作。

例:建立「社交」檢視 = 公會 + 好友 + 密語,獨立視窗只顯示這三種對話,
還可以把視窗貼齊遊戲原本的聊天視窗、開啟置頂,當作濾過的聊天覆蓋層使用。

## 系統需求

- Windows 10 1903 以上(Windows.Graphics.Capture 需求)
- 「中文(台灣)」OCR 語言功能,安裝方式擇一:
  - 設定 → 時間與語言 → 語言與地區 → 中文(台灣) → 語言選項 → 光學字元辨識
  - 系統管理員 PowerShell:
    `Add-WindowsCapability -Online -Name "Language.OCR~~~zh-TW~0.0.1.0"`

## 建置

安裝 [Rust](https://rustup.rs)(stable),然後:

```
cargo build --release
```

產出 `target/release/maple-chat-filter.exe`,單一執行檔、零外部 DLL。
設定檔 `maple_chat_filter.toml` 會自動建立在執行檔旁。

## 介面配置

- **主視窗**:永遠只顯示聊天內容,無邊框(沒有系統的最小化/最大化/關閉鈕)。
  - 工具列(頂端):檢視切換(全部 + 自訂檢視)、搜尋、清空訊息、字體大小、
    視窗置頂、🔓/🔒 鎖定切換、⚙ 設定。
  - 工具列背景可拖曳移動視窗;視窗右邊、下面、右下角可拖曳縮放
    (上面/左邊拿掉了,避免點頻道按鈕時誤觸)。
  - 鎖定後拖曳跟縮放都會被停用,避免疊圖對好位置後不小心誤觸。
  - 結束應用程式的按鈕收在設定視窗裡(主視窗沒有關閉鈕)。
- **設定視窗**:按 ⚙ 開啟,是獨立的作業系統視窗(不是疊在主視窗裡的面板),
  再按一次 ⚙ 會把它叫到最前面。內有四個分頁:擷取設定、頻道/校準、檢視管理、說明。

## 使用步驟

1. **擷取設定**:選擇遊戲視窗 → 開始擷取
2. 在預覽圖上**拖曳框選聊天區域**(ROI,綠框為目前設定),或直接輸入 x/y/w/h 座標
3. **頻道/校準**:開啟校準模式,請朋友在各頻道發話;
   清單會即時列出每行的偵測顏色、OCR 文字,以及送進 OCR 引擎的實際畫面縮圖
   (方便判斷辨識錯誤是遮罩問題還是純粹認錯字),點「套用→」指派給對應頻道
4. **檢視管理**:調整聊天文字大小、設定「全部」檢視的行為(顯示全部對話 or
   隱藏聊天看遊戲原始畫面)、建立自己的分頁與頻道組合、設定切換檢視的快捷鍵
5. 回到聊天畫面,可開啟「視窗置頂」疊在遊戲聊天視窗上面

## 系統層級快捷鍵

預設 **Shift+Tab**,不需要應用程式在前景、遊戲視窗有焦點時也能觸發,
按一次會循環切換檢視(全部 → 檢視1 → 檢視2 → … → 全部)。
可以在「檢視管理」分頁自訂組合鍵(Ctrl/Alt/Shift/Win + 按鍵)。
如果選到的組合鍵被其他程式佔用導致註冊失敗,畫面上會跳出紅色提示。

## 提升辨識率(重要)

- 把遊戲內**聊天視窗背景調成不透明**(黑底),準確率大幅提升
- 遊戲使用**視窗模式或無邊框**(獨占全螢幕無法擷取)
- 預設頻道顏色是近似值,**第一次使用務必校準**
- ROI 的 y 座標要精準對齊聊天訊息**第一行的頂端**——切行是從 ROI 最上面開始,
  依「切行高度」固定往下切,沒對齊會導致每一行都跟著錯位
- 校準時容差別一次調太寬,寬容差雖然比較容易「抓到」文字,但也容易把背景一起
  吃進遮罩,反而讓 OCR 讀出來的圖更花、辨識率更差

## 已知限制

- 遊戲最小化時擷取暫停(WGC 限制)
- 固定切行對齊到聊天視窗大小改變會跟著跑掉,需要重新框 ROI 並確認切行高度
- OCR 仍可能誤認少數字元;相同/相似文字在去重時間窗內只顯示一次
  (用編輯距離模糊比對,能抓住背景抖動造成的 OCR 雜訊誤差,不是只認完全相同字串)
- 長訊息折行以「無發話者 + 同頻道 + 2 秒內」的啟發式合併,偶有誤併
- 螢幕擷取 + OCR 這個技術路線本質上很難做到 100% 準確;如果需要完全精準的
  聊天紀錄,本工具不是適合的方案
